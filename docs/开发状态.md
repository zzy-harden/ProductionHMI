## T05：实现 Modbus TCP 响应解析器

当前实现已完成：

- 解析 MBAP Header；
- 校验 Protocol ID 与 MBAP Length；
- 校验 Transaction ID、Unit ID、Function Code 是否与请求匹配；
- 解析 0x03 / 0x04 读寄存器响应；
- 解析 0x06 写单寄存器响应；
- 解析 0x10 写多寄存器响应；
- 识别 `function | 0x80` 的 Modbus 异常响应并保留 Exception Code；
- 校验读响应 Byte Count、寄存器数量和 Payload 长度；
- 将帧过短、长度错误、请求响应不匹配、设备异常和非法 Payload 分类上报；
- 增加 Modbus 解码 Qt Test；
- 本地纯 C++17 `-Wall -Wextra -Wpedantic -Werror` smoke test 已通过；
- 同步增加面向初学者的 `docs/tasks/T05-Modbus响应解析.md` 学习记录。

T05 的最终验收以 Windows CI（Qt 6 + MSVC 2022）通过为准。CI 未通过前不进入 T06。
