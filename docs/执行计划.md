# 产线设备上位机监控系统——执行计划

> 文档版本：V1.0  
> 目标平台：Windows 11  
> 开发语言：C++17  
> GUI：Qt 6 Widgets  
> 构建：CMake  
> 编译器：优先 MSVC 2022 x64，同时保持 MinGW / Linux Qt 的源码可编译性  
> 通信：Modbus TCP（自行实现应用层编解码，底层使用 QTcpSocket）  
> 数据库：SQLite（Qt SQL）  
> 曲线：QCustomPlot  
> 测试：Qt Test + PLC 模拟器 + 故障注入  

---

# 1. 执行原则

本项目不按“页面列表”推进，而按**可验证的业务闭环**推进。每个任务只解决一个主要问题，并给出明确输入、输出和验收标准。

开发过程遵循以下原则：

1. **先核心后界面**：先打通协议、模拟器、采集与数据模型，再做完整 UI。
2. **先纵向闭环后横向扩展**：先用 1 个 PLC + 少量测点跑通，再扩展到多测点、多设备和性能优化。
3. **通信与 UI 解耦**：任何网络操作不得运行在 UI 主线程。
4. **配置驱动**：测点、阈值、扫描周期和写入范围不在代码中硬编码。
5. **先正确性后性能**：先保证协议、状态、报警和控制语义正确，再做批量读取、节流和降采样。
6. **每个阶段都可运行**：阶段结束时必须有可演示结果，避免最后才整体联调。
7. **测试前置**：协议编解码、地址合并、报警状态机等纯逻辑模块在实现时同步补测试，而不是全部拖到最后。
8. **Windows 为最终目标**：源码不依赖 Linux 专有 API，最终在 Win11 + Qt Creator + MSVC 2022 下完成编译与运行验收。

# 3. 已发现的需求冲突与统一约定

在开始编码前，先冻结以下容易冲突的语义。

## 3.1 操作员权限冲突

已有描述中同时出现过：

- “操作员只读、确认报警”；
- “支持下发启停指令”。

V1.0 统一为：

**操作员**
- 查看实时数据；
- 查看趋势；
- 查看历史报警；
- 确认报警；
- 不允许修改阈值；
- 不允许修改测点配置；
- 不允许修改工艺参数；
- 不允许启停 / 复位设备。

**管理员**
- 具备操作员全部权限；
- 修改阈值；
- 修改工艺参数；
- 修改工程配置；
- 启动 / 停止 / 复位设备。

这样权限边界最清晰。若以后希望操作员可启停，只调整权限矩阵，不修改底层控制逻辑。

## 3.2 “报警确认 / 清除 / 恢复”语义冲突

统一定义：

- **触发**：物理条件满足报警条件；
- **确认**：用户表示“已知晓”，不代表故障消失；
- **恢复**：物理条件已经恢复正常；
- **历史记录不得删除**；
- V1.0 不提供“手动强制清除仍处于活动状态的报警”。

UI 中所谓“清除”仅表示从当前活动列表移除已经恢复的记录，数据库历史仍保留。

## 3.3 “近期历史曲线”与数据库范围

V1.0：

- 实时趋势使用内存有界缓存；
- 可暂停、缩放查看近期数据；
- SQLite 主要保存报警、用户和操作审计；
- 不把所有 100 ms 过程数据永久写入 SQLite。

因此“近期历史”指本次程序运行期间内存中保留的时间窗口。

过程历史持久化作为 V2 扩展，不影响 V1.0 完整性。

## 3.4 单 PLC 与多 PLC

实施顺序：

1. 先完成单 PLC 全链路；
2. 数据结构从第一天保留 `deviceId`；
3. 单 PLC 闭环稳定后扩展为多 PLC；
4. 多 PLC 不是最早阶段的阻塞条件。

最终 V1.0 目标支持多个 PLC 配置，但所有核心功能必须先在单 PLC 下通过。

# 11. 关键风险与控制

## 风险 1：Qt UI 做得太早

后果：界面很多，但底层接口反复改。

控制：T14 之前先完成 T01~T12 主链路。

## 风险 2：自行实现 Modbus 后范围膨胀

控制：只实现 03 / 04 / 06 / 10，不追求全协议。

## 风险 3：多 PLC 过早引入

控制：先完成单 PLC 全链路，再做 T13。

## 风险 4：数据库职责膨胀

控制：V1.0 不永久保存所有高频过程数据。

## 风险 5：线程模型失控

控制：

- UI 主线程只做 GUI；
- 通信对象固定归属通信线程；
- QObject 不跨线程直接调用；
- 跨线程使用 queued signal/slot；
- 不随意创建线程。

## 风险 6：报警语义不清

控制：以状态机为唯一真实来源，UI 不自行判断报警。

## 风险 7：为了“高级”加入无业务理由的技术

控制：V1.0 不加入 epoll、共享内存、微服务、MQTT、OPC UA 等非必要内容。
